# آناتومی مهندسی پکیج دیواری ایران رادیاتور (سری L / M / E دو مبدله)

مدل ایزومتریک تعاملی سه‌بعدی (SVG) و شبیه‌ساز عیب‌یابی پکیج دیواری ایران رادیاتور.

🌐 **دموی زنده (Live Demo):**
- [مشاهده نسخه اصلی (Dark Theme)](https://rezzzz77.github.io/iran-radiator-boiler/)
- [نسخه روشن (Light Theme)](https://rezzzz77.github.io/iran-radiator-boiler/index-light.html)

## امکانات
- **۲۲ قطعه مهندسی ایزومتریک تعاملی:** مشعل اتمسفریک و الکترود جرقه/یونیزاسیون، مبدل اصلی مسی، مبدل ثانویه صفحه‌ای ۱۶ پلیت، شیر سه‌طرفه موتوری، شیر گاز SIT 845، پمپ سیرکولاتور با ایرونت، فلومتر توربینی، شیر پرکن دستی، پرشر سوئیچ آب و هوا، سنسورهای NTC، ترموستات حد ۱۰۵ درجه، شیر اطمینان ۳ بار، منبع انبساط و برد اصلی الکترونیک.
- **جریان هیدرولیک و گاز زنده:** نمایش مسیر رفت و برگشت شوفاژ، اولویت آبگرم مصرفی (DHW Priority)، مدار پرکن و تخلیه دودکش.
- **شبیه‌ساز کدهای خطای برد آنالوگ (LED ۳۰ تا ۸۰):** `40-70`، `40-60-80`، `70-80`، `80`، `50-80` و `50-70` به همراه بازیابی خطای افت فشار از طریق شیر پرکن تعاملی.
- **فیلتر لایه‌ای سیستم‌ها:** جداسازی بصری مدارهای احتراق، هیدرولیک، دودکش و الکترونیک + تغییر تم تاریک/روشن.

## ساخت مجدد (Rebuild)

نیاز به Node.js 20+:

```bash
npm run build
```

خروجی‌های مستقل `index.html` و `index-light.html` بدون نیاز به وابستگی خارجی تولید می‌شوند.
